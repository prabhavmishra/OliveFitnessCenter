# Olive Fitness Center Website

A responsive static website for a fitness center, designed to showcase services, facilities, trainers, and contact information with a clean and user-friendly interface.

## 🚀 Live Demo
https://olivefitnesscenter.vercel.app  

---

## 📌 Features
- Responsive multi-page layout (Home & Contact)
- Clean and modern UI for a fitness/gym website
- Service and facility showcase with visuals
- Trainer and workout section highlights
- Organized asset structure for maintainability
